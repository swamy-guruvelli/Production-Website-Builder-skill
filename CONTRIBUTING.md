# Contributing

Contributions that improve the production quality contract without turning it into a framework manual are welcome.

## Principles

- Keep `SKILL.md` focused on orchestration, ownership, and the Definition of Done.
- Put detailed stable requirements in `references/`.
- Keep volatile framework, security, browser, and deployment instructions in specialist upstream skills.
- Prefer outcomes over rigid implementation prescriptions.
- Preserve proportional engineering and explicit prototype exceptions.
- Do not vendor third-party skills without verifying their licenses and preserving notices.

## Development

1. Edit files under `skills/production-web-standard/`.
2. Run `python scripts/validate.py`.
3. Confirm every reference linked from `SKILL.md` exists.
4. Describe the behavior change in the pull request.
